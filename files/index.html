PodBay files

A few small files from the PodBay code, copied here so they can be read without the code repository, which is private (available on request, as is the trained adapter). The guard files are the same code the post and the simulator run in your browser.

  • podbay_rlvr_colab.ipynbColab notebook: load the base model and the adapter, try scenes, and (off by default) train the adapter. It clones the code repository, which is private: available on request.
  • PodBay.commandmacOS launcher: llama-server with the adapter, plus the simulator page. It expects the layout of the code repository (private, available on request).
  • guard/rules.jsonThe guard code's rules: the rungs of the ladder, in order.
  • guard/hashes.jsGuard code (browser): hashes.
  • guard/laws.jsGuard code (browser): operator laws.
  • guard/rules.jsGuard code (browser): the rules, as loaded by the page.
  • guard/ladder.jsGuard code (browser): the ladder that decides every click.
  • guard/key.jsGuard code (browser): the operator-key token.
