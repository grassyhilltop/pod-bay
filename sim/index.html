a 3D-printing cell where a model drives the robot by clicking camera feeds, and guard code decides every click

guard policy

Click anything in a camera view. Your click becomes a computer-use click on that camera's feed. It goes through the same loop a model's click does: Observe (detections), Propose, Guard (the ladder R0 to R7), then Execute, Blocked, Halted or Give up. Switch safeguards off to see what each one stops. The task buttons replay a real model's logged answers; switch the RLVR adapter on and the same model hands some of them back by itself.

    what is in the file

    One line per loop state (observe, propose, guard, then execute, blocked, halted or give up) and per key, law, safeguard-switch, freeze and human-intervention event, in the format podbay.trace/1 (podbay/obs/SCHEMA.md). Each line names who proposed (model, revision, adapter hash and scale, guard policy hash: declared, not attested), on whose key (operator, scope, hash of the laws, expiry: never the key itself), and holds the sha256 of the line before it, so an edited file fails python3 -m podbay.obs.trace <file>. The chain is not signed: compare the last hash shown here with the file's.
